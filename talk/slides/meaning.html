What it says: the subspace holds, the straight move does not, and use is layer-specific

Detection is easy here

All three variables, from block 1, in a trained model, an untrained one and a pixel-reconstruction model. On a single disk, a probe R² answers almost nothing about the model.

The linear picture is half right

Direction lives in a rank-2 linear code, stretched so that a probe count reads it as tens of dimensions. But the code is a ring: the reachable states are a curve inside the subspace, and a straight step leaves them. Speed and acceleration are lines, and there the linear picture is whole.

Use is where the evidence sharpens

Mid-depth edits are repaired within four blocks. Late edits reach the predictor's forecast, and the on-ring path reaches it best. The model treats the ring as the set of real states when it forecasts.

For a physical world model, the question after "the model has it" is "what does the model do with it". On this data the answer depends on where you edit, and the geometry of the variable decides how you have to edit.
