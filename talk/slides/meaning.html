What I think it means

Detection is easy here

All three variables decode from block 1 in the trained model, in an untrained one and in a pixel-reconstruction model. On a single disk a probe R² tells you almost nothing about the model.

The linear picture is half right

Direction lives in a rank-2 linear code, stretched so that a probe count reads it as tens of dimensions. But the code is a ring: the reachable states are a curve inside the subspace, and in the ring's plane a straight step leaves them. In the full 64-D subspace the straight path is no farther from real clips, so the hollow is a fact about the plane. Speed and acceleration are lines, and there the linear picture is whole.

Use depends on the layer

Mid-depth edits are repaired within four blocks. Late edits reach the predictor's forecast. Along the ring route the forecast moves through the intermediate directions; along the chord it stalls, then jumps, with its radius collapsing mid-path. At matched edit size the ring route also lands 8–13° closer. The gain is in forecast angle; position ties. The smoothing spline does worst, so the variant matters as much as the route.

Once you know the model has a variable, the next question is what it does with it. On this data that depends on where you edit, and the variable's geometry decides how you have to edit.
