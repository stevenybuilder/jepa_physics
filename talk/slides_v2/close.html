Closing question

Can a world model run a counterfactual we write into it, at the interface its predictor reads?

Joseph's frame: a world model is the network's own state variables and dynamics.

We found them readable from mid-encoder but used late, or through the object's tokens. That is where a what-if has to be written.

If it works, a world model is steerable one physical variable at a time, and a robot's plan can be checked by editing its state and reading the forecast. If not, the predictor re-derives physics from pixels.
